# Fotos

Carpeta para fotos reales de los hoteles o de los destinos.

Guarda aquí el JPG (1200 px de ancho es más que suficiente) y apunta a él desde
`data/hotels.js`:

```js
"photo": "assets/photos/shanghai.jpg"
```

Si el archivo no existe o falla la carga, se queda la ilustración por defecto.
No hace falta borrar nada ni tocar el código.
